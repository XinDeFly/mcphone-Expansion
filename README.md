# mcphone-Financial-Expansion
Block Finance is a financial-themed mod for Minecraft 1.20.1 (requires MCphone as a dependency), centered around the "World Financial Center." Players can trade stocks, futures, and more.
Stocks: Priced based on item rarity, with daily fluctuations including price limits, surges, and crashes. Supports T+1 selling, commissions, stamp duties, and daily dividends.
Futures: Two-way trading, 10% margin, daily mark-to-market settlement, delivery after 3 in-game days. Forced liquidation occurs if losses exceed the threshold.
Spot Trading: Buy and sell real items directly using balance, with a persistent 27-slot independent storage that can interact with your inventory.
All interfaces feature 15-day K-line charts, Chinese/English search, and hover to view rarity and market details. Additional features include a convenient trading platform, public market terminal, lockable dual-container counter (auto-item transfer), and decorative computer blocks. Integrated with the MCphone app store, allowing trading anytime via the landscape mobile phone app.
