# mcphone-Expansion

Block Finance is a comprehensive financial-themed mod for Minecraft 1.20.1, requiring MCphone as a mandatory dependency. It is built around the concept of a "World Financial Center," where players can engage in realistic stock, futures, and spot trading within the game world. The mod introduces a fully functional economic simulation that mirrors real-world financial markets while remaining accessible and engaging for Minecraft players.

Stock Trading: Each item in the game is assigned a base price according to its rarity. Prices fluctuate daily with randomized volatility, including mechanisms such as price limits (up/down by a fixed percentage), sudden surges, and dramatic crashes. Players can buy shares and sell them using a T+1 rule—meaning trades settle one day after purchase. Realistic transaction costs apply, including commissions and stamp duties. Additionally, stocks pay daily dividends based on the performance of the underlying item economy, rewarding long-term holders.

Futures Trading: Futures contracts allow two-way trading (both long and short positions). A margin system requires only 10% of the contract value to open a position. Daily mark-to-market settlement ensures gains and losses are reflected in real time. Contracts expire after three in-game days, at which point physical delivery occurs. If a player's losses exceed a certain threshold, forced liquidation is triggered automatically to prevent negative balances.

Spot Trading: This mode enables direct buying and selling of real items using the player's in-game currency balance. A dedicated 27-slot persistent storage unit is provided, which can be accessed independently or linked to the player's main inventory for seamless item transfers. All transactions are recorded and settled instantly.

Every trading interface includes interactive 15-day K-line charts for technical analysis, a bilingual Chinese/English search function, and hover tooltips that display item rarity, current price trends, and detailed market information. Beyond these core features, the mod adds several utility blocks and devices: a convenient trading platform for quick orders, a public market terminal accessible by multiple players, a lockable dual-container counter that automatically moves items between input and output chests, and decorative computer blocks to enhance the financial district aesthetic.

The entire system is integrated with the MCphone app store, allowing players to execute trades anytime through a landscape-oriented mobile phone application. This cross-device functionality ensures that even when away from a dedicated trading terminal, players can monitor markets and place orders.

This mod provides interfaces for additional options and other UI extensions.
