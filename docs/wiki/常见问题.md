## 安装与启动

**Q：启动时报缺少前置 / 直接崩溃？**
A：本模组**必需** [MCphone](https://github.com/november521/mcphone) 0.10.2 及以上。
请确认 `mods/` 里同时有 MCphone 与本模组，并且版本匹配（Minecraft 1.20.1 + Forge 47.4.0+）。

**Q：服务器上能用吗？**
A：能。**服务端与客户端都必须安装**：价格与机箱自动化在服务端计算，界面在客户端绘制。
只装客户端会连不上，只装服务端会缺少界面。

**Q：支持哪些 Minecraft 版本？**
A：目前仅 **1.20.1 / Forge**。其它版本未适配。

## 交易相关

**Q：价格是谁定的？会同步吗？**
A：由服务端统一维护并每日更新，全服同一时间价格一致，随存档持久化；重进游戏不会重置。

**Q：买了东西扣钱但没收到物品？**
A：请检查背包是否已满。若仍异常，请带着「操作时间 + 物品名 + 数量」到
[Issues](https://github.com/XinDeFly/mcphone-Expansion/issues) 反馈。

**Q：可以只做客户端模组吗？**
A：不可以，本模组的行情与自动化是服务端权威逻辑。

## 电脑设备与机箱

**Q：显示器里看不到机箱 / 方位按钮是灰的？**
A：机箱必须放在显示器的**相邻方块**（上 / 下 / 左 / 右 / 前 / 后）。没有机箱的方向会显示为灰色空位。

**Q：机箱能存多少东西？**
A：基础 9 格；每插一条内存条 +9 格，最多 8 条 → **81 格**。

**Q：内存条从哪来？**
A：图书管理员村民处用 **3 金锭**交易获得；也可自行合成。

**Q：取出内存条时提示无法取出？**
A：这是保护机制——若缩容后会有物品超出容量，则拒绝取出，避免物品被隐藏或丢失。先把超出的物品取出即可。

**Q：存储格子里的物品图标不显示？**
A：请更新到 **4.5.1 或更高版本**，该问题已修复（根因是扩展行的物品同步与行映射竞态）。

**Q：自动化规则不触发？**
A：逐项检查：
1. 机箱**角色**是否匹配（购入类规则只在「购入」机箱生效，出售类只在「出售」机箱生效）；
2. 触发时机是否满足（「达价」需要价格真的越过阈值；「红石」需要满足信号条件）；
3. 该规则**是否已启用**（「启停」可切换），且**当日是否已触发过**（同一规则每日最多一次）；
4. 出售需要机箱内存有该物品，购入需要钱包余额足够。

## 界面操作

**Q：搜索框支持拼音吗？**
A：支持。中文名、拼音全拼（`tiekuai`）、拼音首字母（`tk`）都能匹配；英文物品 ID 已不再参与匹配。

**Q：在搜索框里打字会误触发背包 / 丢弃快捷键吗？**
A：不会。文本框编辑状态下会屏蔽 E（背包）、Q（丢弃）、F（副手）、数字键（快捷栏交换）等游戏快捷键。

**Q：改「视频设置 → 界面尺寸」后格子会错位吗？**
A：不会。外框与内容（含槽位、图标、输入框）使用同一套缩放，任意档位都对齐。

**Q：滚轮滚动存储格子时物品会乱位吗？**
A：4.4.9 起已修复；请使用最新版本。
