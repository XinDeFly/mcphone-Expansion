# MCphone 市场扩展 · 使用指南

[首页](Home) ｜ [使用指南](使用指南) ｜ [常见问题](常见问题)

本页说明游戏内的完整玩法：交易终端、手机金融 App、电脑设备与机箱自动化。

## 一、物品与方块

| 名称 | 来源 | 用途 |
|---|---|---|
| 美元纸钞 | 合成 | 交易用的货币道具 |
| 便捷交易平台 | 合成 | 右键打开金融交易终端（现货 / 期货 / 股票） |
| 公共市场终端 | 合成 | 公共市场，用于集中交易与展示 |
| 电脑显示器 | 合成 | 机箱控制台：选择机箱、管理存储与自动化规则 |
| 电脑机箱 | 合成 | 存储物品、按规则自动买卖；容量随内存条增加 |
| 内存条（存储元件） | 图书管理员村民：**3 金锭** | 插入机箱，每条 **+9 格**存储（上限 81 格） |

## 二、金融交易终端

右键「便捷交易平台」打开终端：

- **现货**：按当前报价买入 / 卖出物品，价格每日更新；**卖出按物品稀有度收取 5.0%~15.0% 手续费**（详见第六节）。
- **期货**：开仓 / 平仓，按行情波动结算。
- **股票**：持有与查看持仓。
- **钱包**：买卖均以钱包余额结算，余额显示在界面内（**两位小数**）；余额不足时无法下单。
- **搜索**：列表上方搜索框支持**中文名、拼音全拼、拼音首字母**（例如 `tiekuai`、`tk` 都能找到「铁块」）。

价格由服务端统一维护：全服同一物品在同一时间价格一致，并随存档持久化。

## 三、手机金融 App（需 MCphone）

安装 MCphone 后，手机里会多出一个「金融」App：

| 页面 | 内容 |
|---|---|
| 行情 | 现货 / 期货报价列表，支持中文与拼音搜索 |
| 下单 | 选择物品与数量，买入 / 卖出 |
| 持仓 | 查看当前持仓与浮动盈亏 |
| 帮助 | 玩法说明 |

手机端与桌面终端共用同一套行情与钱包数据，在哪边操作都一样。

## 四、电脑设备

### 摆放

1. 放置「电脑显示器」（面向玩家）。
2. 在显示器**相邻的任意一个方向**（上 / 下 / 左 / 右 / 前 / 后）放置「电脑机箱」。
   一台显示器最多可管理周围 6 台机箱，界面里用九宫格方位按钮切换。

### 机箱元件界面

右键机箱打开：显示主板（CPU + 左右各 4 条内存插槽）与电源面板。
把「内存条」插入内存插槽即可扩容，**每条 +9 格**，最多 8 条（基础 9 + 8×9 = **81 格**）。
取出内存条时，若缩容会导致物品超出容量，会拒绝取出并提示，物品不会丢失。

### 显示器控制台

右键显示器打开控制台：

| 区域 | 说明 |
|---|---|
| 左列 | 现货交易区（与终端一致，可搜索、可直接买卖） |
| 中列 | 机箱存储：4 行视口，可用滑条 / 滚轮**平滑滚动**查看全部格子；背包与快捷栏在下方 |
| 右列 | 机箱控制：钱包余额、方位选择、角色 / 红石 / 触发时机、规则编辑 |

**方位按钮**：「上 / 左 / 前 / 右 / 后 / 下」九宫格，只有存在机箱的方向才可点击，当前选中的机箱按钮会呼吸闪烁。

## 五、自动化交易规则

在控制台右列，先选择机箱方位，再设置：

| 设置 | 取值 | 含义 |
|---|---|---|
| 角色 | 购入 / 出售 / 存储 | 决定机箱执行哪类规则（购入类规则只在「购入」机箱生效，出售类只在「出售」机箱生效） |
| 红石 | 忽略 / 需信号 / 需无信号 | 红石类触发时的前置条件 |
| 触发 | 更新后 / 达价 / 红石 | 规则何时执行 |
| 物品 | 左侧列表当前选中物品 | 规则作用的物品 |
| 方向 | 买入 / 卖出 | 规则动作 |
| 阈值 | 数字 | 触发价格（卖出为「价格 ≥ 阈值」，买入为「价格 ≤ 阈值」） |
| 数量 | 数字 | 每次成交数量 |

点「保存规则」写入机箱，按钮下方会显示**完整参数反馈**（物品、方向、阈值、数量、触发时机）；
「删除」删除当前物品的规则，「启停」启用 / 停用该规则。
同一规则**每日最多触发一次**。资金走机箱绑定玩家（放置者）的钱包。

## 六、稀有度与经济系统

物品按 **7 级稀有度**定价，等级与 [Rarity Core](https://www.curseforge.com/minecraft/mc-mods/raritycore) 一致；
**等级越高，基准价、日波动幅度与卖出手续费都越大**。

| 等级 | 名称 | 基准价区间 | 日涨跌上限 | 卖出手续费 |
|---|---|---|---|---|
| 1 | 普通 | $10 – $30 | 10% | 5.0% |
| 2 | 稀有 | $31 – $70 | 20% | 6.5% |
| 3 | 罕见 | $71 – $150 | 35% | 8.0% |
| 4 | 史诗 | $151 – $400 | 55% | 9.5% |
| 5 | 传说 | $401 – $1,000 | 80% | 11.0% |
| 6 | 神话 | $1,001 – $3,000 | 110% | 13.0% |
| 7 | 唯一 | $3,001 – $10,000 | 150% | 15.0% |

### 卖出手续费

- 适用界面：**便捷交易平台、公共市场终端、手机现货页**（凡卖出物品之处）。
- 计算方式：`手续费 = 当前价格 × 数量 × 该物品的稀有度费率`，**从到账金额中直接扣除**。
- 卖出后聊天栏会给出明细，例如：
  `现货卖出成功：钻石 ×10，成交 $250.00，手续费 $23.75（史诗 9.5%），到账 $226.25`

### 货币精度

- 金额内部以「分」精算（100 分 = $1），界面统一显示**两位小数**（钱包、实时价格、持仓、保证金、K 线悬停价格等）。
- **旧存档自动迁移**：首次进入时把整元金额 ×100（一次性），余额数值保持不变。

### 稀有度从哪里来（自动降级，缺谁都能跑）

1. 已安装 **Rarity Core** → 直接采用它的评级（与游戏内悬浮提示完全一致）；
2. 未安装 → 使用本模组**内置的稀有度快照**（1262 条，覆盖全部已注册物品）；
3. 快照未收录的物品 → 按原版稀有度映射兜底。

相关命令（需要 OP 权限等级 2）：

| 命令 | 作用 |
|---|---|
| `/mcme rarity info` | 查看当前数据来源与快照条目数 |
| `/mcme rarity export` | 把当前全部物品的稀有度导出到 `config/generated_mod/`（JSON + CSV） |

> 装了新模组或调整过 Rarity Core 评级后，重新执行一次 `/mcme rarity export` 即可刷新快照。

## 七、小贴士

- 存储格子支持原版全部操作：左键取放、右键分半、**按住右键拖拽逐个摆放**、左键拖拽平均分堆、
  Shift+左键快速移动（优先放进当前可见的 4 行）、数字键交换、双击收集、Q 丢弃。
- 在搜索框里可以直接打 `e`、`q`、`f` 和数字，不会误触发原版的背包 / 丢弃 / 交换快捷键。
- 界面支持「视频设置 → 界面尺寸」的各档缩放，格子与边框会一同缩放，不会错位。
